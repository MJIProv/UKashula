# UKashula

GitHub Actions learning and documentation repository

## Names

Three names, three jobs. They are not alternatives to each other.

| Name | Where it is used | Who sees it |
|---|---|---|
| **UKA** | the public, user-facing name of the app | growers, traditional councils, the store listing, all marketing |
| **The Heart** | the internal name of the platform and its module graph (`/the-heart`, "Module J of The Heart") | engineers, specs, code comments |
| **Ukashula** | the formal name of the platform and the legal entity | patents, CIPC filings, contracts, the US formation pack |

So: a grower opens **UKA**. An engineer works on **The Heart**. A lawyer writes
**Ukashula**.

"The Heart" is deliberately kept. It is a good name and it is the right name for
what it describes — the platform's core and its module graph. It was never
user-facing: every occurrence in this repository is either an architectural
reference or a provenance citation, and renaming those would have falsified
them. Three of them cite The Heart as the **source** of the 2,400 kg biomass
threshold (`SPEC.md` §4, `domain/rules.ts`, `test/housing-accrual.test.ts`);
rewriting a citation changes what the source says, so they stay as written.

`Ukashula` likewise stays untouched: it is the name on the filings, so changing
it would mean re-papering the patent applications, the YENDRA C resolutions and
the US formation pack.

**The practical rule:** if a string will ever be read by a grower, it says
**UKA**. Everything else keeps the name it already has.
